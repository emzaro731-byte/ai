# AI API Server

Backend for a Flutter/Android AI app with client API keys and multimodal OpenAI features.

## Cloudflare Workers deployment

This repository now includes a Cloudflare Workers version in `src/worker.js` and automatic GitHub Actions deployment in `.github/workflows/deploy-cloudflare.yml`.

Cloudflare Workers Free currently includes up to 100,000 requests/day. citeturn0search2

### GitHub secrets required

In GitHub: **Settings → Secrets and variables → Actions → New repository secret**.

Add:

- `CLOUDFLARE_ACCOUNT_ID` — your Cloudflare account ID.
- `CLOUDFLARE_API_TOKEN` — a Cloudflare API token with Workers deployment permissions.
- `OPENAI_API_KEY` — your server-side OpenAI API key.
- `ADMIN_SECRET` — a long random secret used to create/revoke client API keys.

Cloudflare's official GitHub Actions setup requires the account ID and API token as CI secrets. citeturn0search1

After these four secrets are added, every push to `main` deploys the Worker automatically.

## API

All AI endpoints require `x-api-key` using a client key generated by the admin endpoint.

- `GET /health`
- `GET /api/models`
- `POST /api/chat` — body can include `model`, `input` or `messages`, plus model options
- `POST /api/images/generate` — body: `{ "model": "gpt-image-2", "prompt": "..." }`
- `POST /api/audio/speech` — body: `{ "model": "gpt-4o-mini-tts", "voice": "alloy", "input": "..." }`
- `POST /api/videos` — forwards video-generation job creation
- `GET /api/videos/:id` — retrieves a video job

Admin-only:

- `POST /api/keys`
- `POST /api/keys/revoke`

### Important API-key note

The Cloudflare Worker currently keeps generated client API keys in Worker memory. That is suitable for initial testing, but Worker instances can restart, so keys are not guaranteed to survive a restart or be shared across all instances.

For a production app, the next upgrade should move the key store to Cloudflare D1. D1 is available on the Workers Free plan with daily free limits. citeturn0search0turn0search3

### Music

The audio route currently provides speech/voice audio. It does not pretend to provide a dedicated music-generation model when one is not available in the configured OpenAI API account. A separate music provider can be integrated later without exposing its secret to the Flutter app.

## Security

Never put `OPENAI_API_KEY` in the Flutter APK. Keep it as a Cloudflare Worker secret. The Flutter app should only receive the generated `ai_...` client API key.

The original Node/Express server remains in `src/server.js` for local/VPS use; Cloudflare deployment uses `src/worker.js`.
